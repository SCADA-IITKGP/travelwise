# Six workstreams and acceptance evidence
| Workstream | Work | Evidence |
|---|---|---|
| Domain spec & evaluation | Scope, gold answers, refusal policy | Frozen dataset and baseline |
| Prompt engineering | Prompt comparison, structured output | Prompt version table/schema tests |
| RAG/retrieval | Chunking, hybrid search, reranking, citations | Recall@K, MRR/nDCG, citation tests |
| Agent orchestration & tools | Planner/executor/critic, tools, state, memory | Tool traces and bounded loop |
| Observability & safety | Tracing, taxonomy, injection and PII tests | Trace dashboard and security results |
| Front-end & deployment | UI, containers, rate limits, caching, demo | Running deployment and smoke tests |

Week 1 freeze evaluation set and baseline before agent code. Week 2 retrieval. Week 3 agent/tool workflow. Week 4 safety, tracing, deployment, report and demo.
